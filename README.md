# Salesforce Validation Rule Manager

A full-stack Salesforce integration application that allows users to dynamically authenticate with any Salesforce org and manage Salesforce validation rules directly from a web interface.

https://github.com/akaash37/salesforce-validation-rule-manager

---

# Features

- Salesforce OAuth 2.0 Authentication
- Dynamic Multi-Org Support
- Fetch Salesforce Validation Rules
- Activate / Deactivate Validation Rules
- Salesforce Tooling API Integration
- React.js Frontend
- Node.js + Express.js Backend
- Professional Responsive UI
- Deployment on Vercel and Render
